Use Google Gemini inside Claude Code

Get a second-opinion code review from Gemini, or hand Gemini a bug to investigate or fix, without leaving Claude Code. The plugin runs Gemini through Google's Antigravity CLI (agy), which works with personal Google accounts.

Install in Claude Code View on GitHub
Claude Code
# 1. Install and sign in to the Antigravity CLI: run agy, then /login
/plugin marketplace add azixxxxx/gemini-plugin-cc
/plugin install gemini@gemini-cc
/reload-plugins
/gemini:setup
/gemini:review

What you get

The same workflow as OpenAI's Codex plugin for Claude Code, with Gemini doing the work.

/gemini:review

Code review

A read-only Gemini review of your uncommitted changes or your branch, with findings ordered by severity.

/gemini:adversarial-review

Adversarial review

A steerable review that challenges the design, the assumptions, and the failure modes of a change.

/gemini:rescue

Task delegation

Hand Gemini an investigation or a fix. It edits your working tree and leaves the changes uncommitted.

/gemini:status · result · cancel

Background jobs

Run long reviews and tasks in the background, check on them, read the result, or stop them.

/gemini:setup --enable-review-gate

Review gate

Optionally have Gemini review Claude's last turn before Claude Code stops, and block the stop on real issues.

tool guard

Enforced limits

A per-run guard keeps reviews read-only and blocks git commit, git push, and edits outside the repository.

How it works

Each job is one headless agy run. A hook the plugin writes for that run checks every tool call before agy executes it.

Safety model

The limits are enforced at run time, not only described in the prompt.

  • Read-only reviews. Reviews and read-only tasks may only view files inside the repository. Shell commands, edits, web and MCP tools, and subagents are denied.
  • No commits or pushes. Rescue runs can edit your working tree, but the guard blocks git commit, git push, edits outside the repository and temp folders, and edits inside .git.
  • Sandboxed commands. On macOS and Linux, write-capable runs use agy's terminal sandbox, which keeps shell commands out of the repository and your home folder.
  • Checks itself. A hook marks the guard as loaded before every model call; a run without the mark is stopped at Gemini's first tool call, and a guard that cannot decide blocks the call.
  • Honest limits. Write-capable runs keep network access for shell commands; /gemini:setup --disable-web turns off web and MCP tools. SECURITY.md lists what the plugin does not protect against.

FAQ

How do I use Gemini in Claude Code?

Install the Antigravity CLI (it ships with Google's Gemini desktop app, or install it from antigravity.google/download) and sign in with agy and /login. Then run /plugin marketplace add azixxxxx/gemini-plugin-cc and /plugin install gemini@gemini-cc in Claude Code, and use /gemini:review or /gemini:rescue.

Does it work with a personal Google account?

Yes, as long as Antigravity accepts the account and its location. The plugin is tested with a personal Google account on agy 1.3.5.

Why the Antigravity CLI and not Gemini CLI?

Since June 2026 Gemini CLI rejects personal Google accounts with IneligibleTierError. Version 0.1.0 used Gemini CLI; version 0.2.0 moved to the Antigravity CLI.

How is it different from OpenAI's codex-plugin-cc?

It is a fork with the same commands, background jobs, and review gate, but it calls Gemini through agy instead of Codex.

Can Gemini change my files, commit, or push?

Reviews cannot change anything. Rescue runs can edit your working tree, but the tool guard blocks git commit, git push, and edits outside the repository. The commit and push check is a guardrail, not a security boundary.

Can reviews run commands such as grep or the tests?

No. agy only runs shell commands with --dangerously-skip-permissions, which would leave the plugin's guard as the only barrier, so reviews view files only and get the diff and the repository's file list. Use /gemini:rescue when Gemini should run tests.

Does it work on Windows?

Not supported: the tool guard is off on Windows. macOS is tested, and the test suite also runs on Linux.

What does the plugin send to Google?

The prompt it builds (for reviews: the diff, untracked files within a budget, and the repository's file list) and the files Gemini opens. agy sends them to Google's models under your account.
